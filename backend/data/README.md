# Backend Data Directory

Place DTC e-ticketing data files here (not committed to git):

## Expected Files
- `october_2026_tickets.csv` — Raw e-ticketing export (~2.56M rows)
  - Columns: `passenger_count`, `amount`, `vehicle_number`, `ticket_type_id`, `start_stop_name`, `end_stop_name`, `route`, `created_at`, `is_ac`
- `delhi_gtfs/` — GTFS static feed directory
  - `stops.txt`, `routes.txt`, `stop_times.txt`, `trips.txt`, etc.
- `processed/crowd_features.parquet` — Engineered features (generated by data pipeline)

## Data Pipeline

Run the preprocessing pipeline once you have the raw CSV:

```bash
# From repo root
python backend/scripts/preprocess.py --input data/october_2026_tickets.csv
```

This will generate:
- `data/processed/crowd_features.parquet` — Aggregated hourly crowd features
- `data/processed/route_stats.parquet` — Per-route statistics
- `data/models/crowd_model.txt` — Trained LightGBM model
